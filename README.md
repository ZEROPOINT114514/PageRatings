# PageRating

一个用于 MediaWiki 的文章评分扩展。
提供 6 档加权投票、按评分排序的排行特殊页面
`Special:查看文章评分`，以及一个高度可定制的
`{{投票}}` 模板。

## 特性

- **6 档投票**：+1（出类拔萃）、+0.5（笔酣墨饱）、
  0（差强人意）、-0.5（千篇一律）、-1（平淡无味）、
  以及「取消我的投票」。
- **分组评分（1.1.0）**：文章使用子模板 `{{投票/X}}`（如 `{{投票/Crossover}}`）时，其评分自动归入同名分组，
  并在 **Special:X**（如 `Special:Crossover`）汇总展示；`Special:查看文章评分` 只显示使用基础 `{{投票}}` 的页面。
- 分组特殊页面由扩展**自动注册**；若同名特殊页面已被占用，`模板:投票/X` 页面本身会以**红字警告**提示无法汇总。
- **Special 页**:`Special:查看文章评分` 以表格展示所有已登记
  页面的评分与投票分布，**自高到低**排序。
- **公式**:
  ```
  {[(投+1人数)-(投-1人数)]+[(投+0.5人数)-(投-0.5人数)]×0.5} ÷
  (总投票人数，含投0的人数)
  ```
- **模板 `{{投票}}`**:
  - 可自定义背景图（File:Media 文件名或 http(s) URL）
  - 可自定义卡片的「点击前」两段文字
  - 提供默认 / 悬停 / 确认三种视觉态（由前端 CSS 控制）
  - 「确认态」标题中自动显示当前文章名称
- **自动登记**: `ArticleSaveComplete` 钩子识别模板存在与否，
  模板被加入时自动添加排行记录；模板被删除时自动移除。

## 自定义

修改模板样式、颜色、动画，编辑
[`resources/ext.pageRating.css`](resources/ext.pageRating.css)。
所有视觉变量都以 CSS 自定义属性（`--pr-*`）暴露，
你可以在 wiki 的 `MediaWiki:Common.css` 中覆盖：

```css
:root {
  --pr-accent: #ff5577;
  --pr-bg-image: linear-gradient(135deg, #4a90e2, #1b3a6f);
}
```
